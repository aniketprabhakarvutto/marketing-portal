How access works: Choose the Google account and approve the request on Google's permission screen. An email address by itself does not grant access. The portal requests send-only permission and cannot read, search, or delete inbox messages.

OAuth credentials and refresh token are stored in the local portal database with file permissions. The current local app does not encrypt these values separately. For production use, move them to a managed secret store. Disconnecting removes the token from this portal; to revoke Google's grant too, use Google Account connections.
