# Portal icon licensing decision

Reviewed on 2026-10-28.

The requested URL, `https://www.flaticon.com/?k=1793188745299&log-in=google`, is a Flaticon Google-login entry point. It does not identify an icon, author, pack, download record, or asset-specific license. It is not sufficient evidence that Vutto may copy or redistribute any Flaticon asset.

Flaticon's April 2026 terms state that free use of Flaticon Content requires credit to Flaticon and the contributor. Attribution-free use requires a Premium subscription and the relevant content must be downloaded while that subscription is active. The terms also restrict transfer, sublicensing, and distribution of the source content. Source: <https://www.flaticon.com/legal>, sections 8.1, 8.3, and 9.

No Flaticon asset was copied into this repository. The portal uses a coherent set of simple, first-party line icons drawn directly as SVG paths for this application. This avoids an unverified third-party license, removes external runtime dependencies, and keeps icon rendering consistent. All decorative icons are hidden from assistive technology. Icon-only controls retain accessible names and visible keyboard focus.

If Flaticon assets are requested later, record all of the following before adding them:

1. Exact asset and author URLs.
2. Whether each asset is free, Premium, Sponsored, or editorial-only.
3. The account and subscription basis for the download.
4. The required attribution text and placement, unless a valid attribution-free license applies.
5. Evidence that repository and deployed-application use complies with transfer and distribution restrictions.
